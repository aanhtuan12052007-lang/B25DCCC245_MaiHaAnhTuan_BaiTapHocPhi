# Bài tập học phí sinh viên

**Họ tên:** Mai Hà Anh Tuấn  
**Mã sinh viên:** B25DCCC245  
**Lớp:** INT1332-18

## Nội dung bài làm

- **Câu 1:** Nhập và chuẩn hóa thông tin sinh viên.
- **Câu 2:** Tính học phí theo hệ đào tạo.
- **Câu 3:** Kiểm tra dữ liệu và quản lý danh sách học phí.
- **Câu 4:** Tính học phí sau miễn giảm và thống kê theo hệ.

## Cách chạy chương trình

Mỗi câu nằm trong một thư mục riêng. Mở Terminal tại thư mục tương ứng và chạy:

```bash
javac Main.java
java Main
```

Sau đó nhập dữ liệu theo đề bài.
